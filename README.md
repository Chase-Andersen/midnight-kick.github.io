## Overview
Taniti Travel is a responsive, multi-page tourism website for a fictional island destination.  
The site provides visitors with information about lodging, dining, entertainment, sightseeing, and transportation to help them plan their trip.

This project was built using only core web technologies (HTML, CSS, and JavaScript) to strengthen front-end fundamentals without frameworks.

---

## Features
- Home landing page
- Lodging information
- Dining & food options
- Entertainment activities
- Sightseeing recommendations
- Transportation details
- About page
- Responsive design for mobile and desktop
- Consistent navigation and styling across all pages

---

## Tech Stack
- HTML5
- CSS
- Vanilla JavaScript
- Static images and assets
